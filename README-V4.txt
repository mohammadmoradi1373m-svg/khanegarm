خانه‌گرم — V4 سیستم آپلود تصاویر محصول

وضعیت:
- کد فعلی GitHub بررسی شد.
- فایل اصلی: index.html
- مخزن: mohammadmoradi1373m-svg/khanegarm
- Branch: main

مشکل نسخه فعلی:
1) تبدیل WebP اگر در مرورگر شکست می‌خورد، کل ذخیره محصول متوقف می‌شد.
2) thumbnail اجباری بود.
3) پسوند فایل برای هر چیزی غیر از WebP به jpg تبدیل می‌شد.
4) createImageBitmap در نسخه قبلی قبل از تمام شدن پردازش بسته می‌شد.

رفتار V4:
- ورودی تا 25MB پذیرفته می‌شود.
- عکس معمولی در حالت عادی به WebP تبدیل می‌شود.
- ضلع اصلی تا 2500px کنترل می‌شود.
- حجم خروجی اصلی هدف <= 4.7MB است.
- thumbnail تا 480px و حدود 450KB ساخته می‌شود.
- جهت EXIF در createImageBitmap لحاظ می‌شود.
- اگر encoder/decoder مرورگر شکست بخورد، PNG/JPEG/WEBP سبک بدون تبدیل اجباری آپلود می‌شود تا مدیر بی‌دلیل گیر نکند.
- اگر thumbnail شکست بخورد، تصویر اصلی WebP نباید به خاطر آن متوقف شود.
- PNG شفاف به JPEG fallback نمی‌شود.

نکته مهم:
V4 روی GitHub مستقیماً قابل Push نشد چون اتصال GitHub برای عملیات write خطای 403
(Resource not accessible by integration) برگرداند. بنابراین این بسته برای اعمال روی index.html آماده شده است.

1) کش مرورگر را پاک کن یا Ctrl+F5 بزن.
2) با یک PNG حدود 2.67MB تست کن.

4) سپس یک تصویر بزرگ‌تر تست کن.
